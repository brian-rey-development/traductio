# Decision records

Each file records one decision that shaped Traductio, the options that were on the table and what the choice costs. They are short on purpose, and a new record replaces an old one instead of editing it.

| #                                      | Decision                                                    |
| -------------------------------------- | ----------------------------------------------------------- |
| [0001](0001-translategemma.md)         | Use TranslateGemma for the first pass                       |
| [0002](0002-placeholders.md)           | Send numbered placeholders instead of HTML                  |
| [0003](0003-glossary-in-review.md)     | Apply the glossary in the review pass only                  |
| [0004](0004-cache-every-completion.md) | Cache every completion, keyed by its prompt                 |
| [0005](0005-endnote-markers.md)        | Put dropped endnote markers back by sentence position       |
| [0006](0006-mac-app-drives-cli.md)     | Let the Mac app drive the CLI instead of reimplementing it  |
| [0007](0007-stay-local-by-default.md)  | Keep translation local by default and accept overnight runs |
